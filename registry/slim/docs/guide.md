# Guide

## 安装

```bash
pnpm dlx @weme-ui/weme-ui init
pnpm dlx @weme-ui/weme-ui add weme-ui/slim/button
```

## 约定

- 组件源码、文档与示例共存于同一个 item 目录；在 GitHub 上直接阅读，并由 CLI 随 item 安装。
- website 不托管组件库文档。
- 色板 / Theme / Tokens 见 [UnoCSS Preset 文档](https://github.com/weme-ui/weme-ui/blob/main/packages/unocss-preset/docs/theme/index.md)（色卡：[palette](https://github.com/weme-ui/weme-ui/blob/main/packages/unocss-preset/docs/theme/palette.md)）。
