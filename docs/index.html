// core

两个核心：Registry 与 Preset

组件库的主体是可安装的源码单元，以及它们共同依赖的主题与工具类体系。

core

Registry

可复用的 Vue 组件以源码形式发布。每个 item 自包含实现、文档与示例，按需拷贝进你的仓库。

  • 组件、composables、utils 统一 catalog
  • 依赖与 registryDependencies 可解析
  • 你拥有源码，定制不再靠覆盖样式
了解更多
core

UnoCSS Preset

为组件库提供颜色、Tokens、暗色与工具类规则。主题变量开箱可用，和 Registry 样式对齐。

  • 色板刻度、语义 Tokens、P3 支持
  • class / media 暗色切换
  • Rules 与 Variants 覆盖常用场景

// toolchain

CLI 与 Schema 托住工作流

Schema 定义契约；CLI 负责把 Registry item 装进项目。工具链服务组件库，而不是反过来。

soon

CLI

初始化项目、添加与更新 Registry item。命令形态已定，实现推进中。

  • init 写入配置与依赖
  • add <registry>/<item> 拉取源码
contract

Schema

Registry、配置与 lockfile 的契约。保证 catalog、安装路径与已装 item 可被工具可靠解析。

  • registry / config / lockfile 契约
  • 让 CLI 与工具共享同一套格式
