Button

Used to trigger an action or event.

Live Preview

button-1

examples/button-1.vueLive preview

用于触发操作或事件的按钮组件。

Preview

基础按钮、带图标、加载中与禁用状态。

Installation

pnpm dlx @weme-ui/weme-ui add weme-ui/slim/button

Usage

<script setup lang="ts">
import Button from '~/components/button/button.vue'
</script>

<template>
  <Button label="Click me" />
</template>

Examples

见 examples/button-1.vue：展示 Primary、带图标、Loading 与 Disabled。

Props

属性 说明 类型 默认值
type 原生 button 类型 'button' | 'submit' | 'reset' 'button'
icon 前置图标名称 string —
label 按钮文案 string —
loadingIcon 加载中图标名称 string 'loading'
loadingText 加载中文案 string —
size 尺寸 'sm' | 'md' | 'lg' 'md'
radius 圆角 'none' | 'xs' | 'sm' | 'md' | 'lg' | 'xl' | 'full' 'sm'
disabled 是否禁用 boolean false
loading 是否加载中 boolean false
unstyled 是否去掉默认样式 boolean false
class 根节点额外 class any —
ui 覆盖 slots 样式 Partial<ButtonStyleSlots> —
onClick 点击回调（支持异步） ((event: MouseEvent) => void | Promise<void>) | Array<...> —

Events

本组件通过 onClick prop 处理点击；异步回调执行期间会进入 loading 状态。

Slots

插槽 说明
icon 自定义前置图标，作用域参数：{ icon }
label 自定义文案，作用域参数：{ label }
loading-icon 自定义加载图标，作用域参数：{ loadingIcon }
loading-text 自定义加载文案，作用域参数：{ label, loadingText }
